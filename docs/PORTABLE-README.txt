Commander Table
===============

Run "Commander Table.exe". No installer is needed: everything lives in this folder,
so you can move it anywhere or delete it to uninstall.

On launch the game checks GitHub for a newer version and offers to update itself.
Your own files in the data folder are never overwritten by an update.

Requires the Microsoft Edge WebView2 runtime, which ships with Windows 10 and 11.

Playing with friends uses Steam: have Steam running before you start the game, then choose
"Play with friends", host a game and invite friends from the Steam overlay. Keep
steam_api64.dll next to the exe; the game needs it to start.
